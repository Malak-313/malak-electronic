# Malak Electronics

A simple electronics shop website created for the Advanced Web Programming course at Lebanese International University (LIU).

## Pages
- Home - shop introduction
- Products - six electronics products with photos, prices and Add to Cart
- Cart - products selected, quantity and total price
- About - information about the shop
- Contact - phone, email, location and opening hours

## Technologies
React, JavaScript, JSX, CSS, React Router (`Routes`, `Route`, `Link`), `useState`, Props and JavaScript arrays.

## Getting started
1. Open a terminal in this project folder.
2. Run `npm install`.
3. Run `npm start`.
4. Visit `http://localhost:3000`.

## Notes
- The product images are included in `src/assets`.
- Add to Cart increases the quantity of a product when it is selected again.
- The Cart page shows selected products, quantities, subtotals and total price.
- The cart is temporary and becomes empty after the page is refreshed.
- No login, database, payment or order system is included.
- Phone and email shown on Contact are sample details, not verified shop contact information.
